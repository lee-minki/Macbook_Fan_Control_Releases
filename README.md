# MacBook Fan Control

Mac의 내부 온도와 팬 회전수를 확인하고, 원하는 열감과 소음에 맞춰 냉각 모드를 고르는 메뉴 막대 앱입니다.

[최신 macOS 앱 다운로드](https://github.com/lee-minki/Macbook_Fan_Control_Releases/releases/latest)

## 지원 기종

| 환경 | 사용 가능한 기능 |
|---|---|
| MacBook Pro(M5 Max), 모델 식별자 `Mac17,6`, 팬 2개 | macOS 14 이상에서 온도·RPM 모니터링 및 팬 제어. 기기의 센서와 팬 구성이 검증된 프로필과 일치해야 합니다. |
| 그 외 Apple Silicon Mac(arm64), macOS 14 이상 | 기기에서 읽을 수 있는 온도와 RPM을 표시합니다. 팬 제어는 macOS가 담당합니다. |
| Intel Mac 또는 macOS 13 이하 | 이번 배포판의 실행 대상에서 제외됩니다. |

모델 식별자는 **시스템 정보 → 하드웨어 → 모델 식별자**에서 확인할 수 있습니다. 팬이 없는 Mac에서는 온도만 확인할 수 있습니다.

## 설치와 첫 실행

1. 위의 다운로드 링크를 열고 **Assets**에서 macOS용 앱 배포 파일을 받습니다. 앱을 **응용 프로그램** 폴더로 옮겨 실행합니다.
2. 처음에는 온도와 팬 회전수만 표시되며, 팬은 macOS가 제어합니다. 두 팬이 있는 모델의 일반 창에는 더 빠른 팬의 RPM이 표시됩니다. 메뉴 막대의 팬 아이콘을 열면 팬별 RPM을 확인할 수 있습니다. 읽을 수 없는 값은 **—**로 표시됩니다.
3. 지원 기종에서는 모드를 선택하고 **팬 제어 시작**을 누릅니다. macOS가 요청하면 관리자 인증을 진행합니다. **중지**를 누르면 시스템 자동 제어로 돌아갑니다.

이 배포판은 임시 서명(ad-hoc)을 사용하며 Apple 공증을 받지 않았습니다. macOS Gatekeeper 설정에 따라 실행이 제한될 수 있습니다.

## 냉각 모드

| 모드 | 동작 |
|---|---|
| 팜레스트 쾌적 | 내부 온도를 기준으로 냉각을 일찍 시작해 손이 닿는 부분의 열감을 줄이는 것을 우선합니다. |
| 균형 · 기본값 | 약간의 온기를 허용하면서 팬 소음과 냉각 사이의 균형을 맞춥니다. |
| 배터리 절약 | 온기를 더 허용하고 팬 회전수를 천천히 올려 팬 사용을 줄입니다. |

세 모드 모두 냉각 중에는 PID로 팬 속도를 연속 조절합니다. 온도가 내려가면 천천히 감속하고, 충분히 식으면 macOS 자동 제어로 돌아갑니다. 이때 팬이 **0 RPM**이어도 정상입니다.

**디테일**을 펼치면 검증된 기종에서 선택 모드의 목표 온도, 온도 추종 그래프와 PID 게인을 읽기 전용으로 확인할 수 있습니다.
